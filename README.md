## FAQ

**$21.99/年这台能建站吗？**
能。1 核 1GB 跑 Nginx + PHP + MySQL 的小站在低流量下没问题，但面板、数据库、缓存加起来会吃掉大半内存，建议加 swap 或直接上 2GB 档。

**年付能不能退款？**
公开的套餐页没有列出统一的退款天数，年付前把它当成不可退的支出来规划，或者先买月付线试。

**续费会不会涨？**
特价年付档按同价续费，第二年不会跳涨。结账页会显示续费金额，付款前扫一眼确认。

**能不能中途换机房？**
不能。换机房等于重新买一台再迁移数据，所以第一次下单就把位置选对。

**流量用超会停机吗？**
不会，超配额后是端口限速。

**能装 Windows 吗？**
标准线和特价线只提供 Linux。需要 Windows 走单独的 Windows VPS 产品线，2GB 档 $27.59/月。
